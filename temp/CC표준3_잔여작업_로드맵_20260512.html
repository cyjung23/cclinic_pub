과제 2: Paid Search 랜딩페이지 최적화

일주일 322세션 중 70% 이탈. 랜딩페이지 첫 화면에서 시술 핵심 정보 즉시 노출 여부, 모바일 로딩속도, 전화·상담 버튼 위치 점검이 필요합니다.

과제 3: 네이버 검색 유입 강화

전 기간에 걸쳐 네이버 유입이 3% 이하로 지속 취약합니다. 블로그 포스팅 빈도 증가, 네이버 SEO 강화, 스마트플레이스 소개글 최적화가 필요합니다.

과제 4: 유튜브·Referral 채널 확대

질적으로 가장 우수한 트래픽 소스입니다. 유튜브 영상에 모바일 페이지 링크 적극 배치, 블로그→홈페이지 연동 강화가 필요합니다.

과제 5: 네이버 스마트플레이스 소개글 등록

2,000자 소개글 작성을 완료했으나, 특수문자 오류로 등록이 실패한 상태입니다. 허용 특수문자: - _ ( ) : & ! [ ] , . % + ~ @ * ^ ’ / ? ² ℃ ※ < >. 수정 대상: ▶ → > 또는 * 로, · → , 또는 / 로 대체. 해당 문자만 수정하면 등록 가능합니다.

과제 6: 영문 가격표 이미지 영문화 (신규)

file.cclinic.kr/images/price_en.webp가 현재 한글로 되어 있습니다. 영문 사이트에서 참조하고 있으므로, 가격 정보를 영문으로 변경한 이미지로 교체해야 합니다.

과제 7: 영문 사이트 콘텐츠 동기화 체계 수립 (신규)

한글 사이트(m/) 콘텐츠 변경 시 영문 사이트(en/)도 동기화해야 합니다. 현재는 수동 관리이므로, 변경 시 체크리스트가 필요합니다. 동기화 대상은 en/data/services/ (8개 JSON), en/data/reviews/ (6개 JSON), en/data/media/articles.json, en/data/services-index.json, en/js/ (4개 JS 파일)입니다. 새로운 서비스 추가 시 en/js/service-panel.js의 serviceIdMap에도 엔트리를 추가해야 합니다.

3. 로드맵

단기 (1~2주)

네이버 스마트플레이스 소개글 특수문자 수정 후 재등록(과제 5). GA4 Key Event 설정을 위한 GTM·HTML 구조 확인(과제 1 선행 조사). 영문 가격표 이미지(price_en.webp) 영문 디자인 준비(과제 6).

중기 (1~2개월)

GA4 Key Event 6개 설정 완료 및 데이터 수집 시작(과제 1). Paid Search 랜딩페이지 첫 화면 개선, 모바일 로딩속도 최적화(과제 2). 블로그 포스팅 빈도 증가 — 시술 소개 콘텐츠 2~3편 발행(과제 3). 영문 가격표 이미지 교체 및 영문 사이트 최종 검수(과제 6). 한글↔영문 콘텐츠 동기화 체크리스트 문서화(과제 7).

장기 (3개월 이상)

유튜브 영상 + 블로그 + 홈페이지 연계 콘텐츠 전략 수립(과제 4). GA4 데이터 기반 광고 채널 ROI 분석 및 예산 재배분(과제 1 데이터 축적 후). 영문 사이트 Google Ads 국제 캠페인 검토(영문 트래픽 데이터 축적 후).
