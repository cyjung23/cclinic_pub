## 6. 특이사항 / 주의점

- adhesion·nodule 등 "자기 페이지"는 해당 nav-link에 active 클래스가 붙어 있어, class="nav-link" 패턴 기반 일괄 치환 시 누락됨. 향후 유사 작업 시 active 케이스를 별도 처리해야 함.
- 터미널에 HTML을 직접 붙여넣으면 bash syntax error 발생. 파일 편집은 에디터 또는 perl/sed 명령으로 처리할 것.
- 긴 텍스트를 터미널 heredoc(cat << EOF)으로 붙여넣으면 중간에 잘릴 수 있음. 문서 편집은 VS Code 에디터에서 직접 하는 것이 안전함.
- 결절제거 페이지 자체(nodule-removal-injection)는 유착제거·결절제거가 이미 독립 nav-item으로 구성되어 있어 추가 분리 불필요했음.
