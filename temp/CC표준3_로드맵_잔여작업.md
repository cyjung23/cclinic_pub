## **2\. 핵심 과제 (우선순위순)**

### **과제 1: GA4 Key Event 설정 (최우선)**

현재 전환 추적이 전혀 안 되어 광고비 대비 실제 효과 측정이 불가합니다.

| 전환 행동 | 이벤트 이름 | 트리거 조건 |
| ----- | ----- | ----- |
| 네이버예약 클릭 | click\_naver\_booking | Click URL contains booking.naver |
| 예약 클릭 | click\_reservation | 자체 예약 버튼 URL/class |
| 이메일 상담 클릭 | click\_email\_consult | Click URL contains mailto: |
| 전화 클릭 (대표) | click\_call (param: 02\) | Click URL contains tel:02-838-3380 |
| 전화 클릭 (상담) | click\_call (param: 010\) | Click URL contains tel:010-9832-3380 |
| 카카오톡 클릭 | kakao\_click | Click URL contains [open.kakao.com](http://open.kakao.com/) |

구현 전 확인사항: GTM 설치 여부, 각 버튼의 실제 HTML 구조(데스크탑/모바일 양쪽), 광고 대행사에 설정 요청 가능 여부.

### **과제 2: Paid Search 랜딩페이지 최적화**

일주일 322세션 중 70% 이탈. 랜딩페이지 첫 화면에서 시술 핵심 정보 즉시 노출 여부, 모바일 로딩속도, 전화·상담 버튼 위치 점검이 필요합니다.

### **과제 3: 네이버 검색 유입 강화**

전 기간에 걸쳐 네이버 유입이 3% 이하로 지속 취약합니다. 블로그 포스팅 빈도 증가, 네이버 SEO 강화, 스마트플레이스 소개글 최적화가 필요합니다.

### **과제 4: 유튜브·Referral 채널 확대**

질적으로 가장 우수한 트래픽 소스입니다. 유튜브 영상에 모바일 페이지 링크 적극 배치, 블로그→홈페이지 연동 강화가 필요합니다.

### **과제 5: 네이버 스마트플레이스 소개글 등록**

2,000자 소개글 작성을 완료했으나, 특수문자 오류로 등록이 실패한 상태입니다. 허용 특수문자: \- \_ ( ) : & \! \[ \] , . % \+ \~ @ \* ^ ’ / ? ² ℃ ※ \< \>. 수정 대상: ▶ → \> 또는 \* 로, · → , 또는 / 로 대체. 해당 문자만 수정하면 등록 가능합니다.

### **과제 6: 영문 가격표 이미지 영문화 (신규)**

[file.cclinic.kr/images/price\_en.webp가](http://file.cclinic.kr/images/price_en.webp%EA%B0%80) 현재 한글로 되어 있습니다. 영문 사이트에서 참조하고 있으므로, 가격 정보를 영문으로 변경한 이미지로 교체해야 합니다.

### **과제 7: 영문 사이트 콘텐츠 동기화 체계 수립 (신규)**

한글 사이트(m/) 콘텐츠 변경 시 영문 사이트(en/)도 동기화해야 합니다. 현재는 수동 관리이므로, 변경 시 체크리스트가 필요합니다. 동기화 대상은 en/data/services/ (8개 JSON), en/data/reviews/ (6개 JSON), en/data/media/articles.json, en/data/services-index.json, en/js/ (4개 JS 파일)입니다. 새로운 서비스 추가 시 en/js/service-panel.js의 serviceIdMap에도 엔트리를 추가해야 합니다.

---

### **과제 8: 결절제거주사 모바일 페이지 구축 및 라이브 배포 (신규·최우선)**

결절제거주사(9번째 시술) 데스크탑 페이지는 dev 브랜치에 구축 완료되었으나 모바일 페이지(m/)와 라이브 배포가 남아 있습니다. 모바일 페이지에 결절제거 메뉴 및 바디케어 재구성을 반영하고, sitemap.xml에 결절제거 URL 등록(24→25개) 및 lastmod 갱신 후, dev→main 병합으로 라이브 배포해야 합니다. 배포 완료 후 CC표준1 시술 8종→9종 및 홈페이지 구조표를 갱신합니다.

## **3\. 로드맵**

### **단기 (1\~2주)**

네이버 스마트플레이스 소개글 특수문자 수정 후 재등록(과제 5). GA4 Key Event 설정을 위한 GTM·HTML 구조 확인(과제 1 선행 조사). 영문 가격표 이미지(price\_en.webp) 영문 디자인 준비(과제 6).

### **중기 (1\~2개월)**

GA4 Key Event 6개 설정 완료 및 데이터 수집 시작(과제 1). Paid Search 랜딩페이지 첫 화면 개선, 모바일 로딩속도 최적화(과제 2). 블로그 포스팅 빈도 증가 — 시술 소개 콘텐츠 2\~3편 발행(과제 3). 영문 가격표 이미지 교체 및 영문 사이트 최종 검수(과제 6). 한글↔영문 콘텐츠 동기화 체크리스트 문서화(과제 7).

### **장기 (3개월 이상)**

유튜브 영상 \+ 블로그 \+ 홈페이지 연계 콘텐츠 전략 수립(과제 4). GA4 데이터 기반 광고 채널 ROI 분석 및 예산 재배분(과제 1 데이터 축적 후). 영문 사이트 Google Ads 국제 캠페인 검토(영문 트래픽 데이터 축적 후).
