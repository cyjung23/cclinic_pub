## 운영 규칙

- 문서 파일이 너무 커지면(대략 250줄 초과) 주제 기준으로 분할합니다.
- 새 시술 추가 등 큰 변경 시 01~09 중 해당 파일과 08(이력)을 함께 갱신합니다.
- `ToBeDeleted/` 폴더는 구버전 문서 보관용이며 검증 후 삭제 예정입니다.
